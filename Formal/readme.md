# 2026 电赛信号类

## 赛题分析Prompt

````markdown
你是一名资深电子设计竞赛（电赛）教练，专攻信号类题目。我已上传本次赛题的 PDF 文件，请仔细阅读全部内容（包括题目要求、各项技术指标、附录中指定的器件清单等）。你必须严格按照以下顺序输出所有内容，每部分都需详细且可直接使用，保证代码和设计在典型电赛环境中能够验证。注意：所有涉及器件的地方，只需给出关键性能指标（如增益、带宽、分辨率、采样率、压摆率等），不要指定具体型号。

### 一、赛题分析
1. 题目背景与功能要求：用你自己的话总结题目要实现的完整功能。
2. 关键性能指标：列出所有明确给出的指标（如带宽、增益、信噪比、失真度、频率范围、分辨率等），并标注哪些是硬性指标，哪些是加分项。
3. 方案选择与比较：给出至少两种可行的顶层方案（含核心器件链、信号流），从复杂度、成本、精度、可实现性等角度进行对比，并给出你的推荐方案及理由。
4. 关键模块指标要求：基于推荐方案，逐一列出各功能模块所需达到的关键性能指标，并说明这些指标如何满足赛题要求。包括但不限于：
   - 放大器：增益、-3dB 带宽、等效输入噪声密度、压摆率、共模抑制比等；
   - 滤波器：类型、阶数、截止频率、带内平坦度、阻带衰减等；
   - ADC：分辨率、采样率、信噪比(SNR)、无杂散动态范围(SFDR)、输入范围等；
   - DAC：分辨率、更新率、建立时间、输出范围等；
   - 处理器（MCU/FPGA）：运算速度、RAM/Flash容量、需要的专用外设（如高精度定时器、高速ADC、DMA等）、接口类型及速率；
   - 电源：各路电压、电流能力、纹波/噪声要求等。
5. 系统总体框图描述：用文字详细描述信号从输入到输出的完整处理流程，为后续框图绘制提供依据。描述中仅使用“放大器”、“滤波器”、“ADC”、“处理器”、“DAC”等通用模块名称，并标注其关键参数。

### 二、参考代码
根据推荐方案，编写核心处理器的完整参考代码。考虑到具体器件未定，代码需具备良好的可移植性和参数化设计：
- 若使用 MCU（如基于 ARM Cortex-M 的处理器），给出标准代码框架，包括：系统初始化、外设配置（ADC、DAC、DMA、定时器等，用注释说明配置参数的确定依据，比如采样率应设为 xxx、缓冲区大小应为 yyy 等）、核心算法函数（如 FFT、数字滤波、调制解调、峰值检测等，并给出 FFT 点数、窗函数、滤波器系数等关键参数的计算依据）、主循环或中断服务程序。代码写法可参照典型 HAL 库风格，但不限于特定芯片。
- 若使用 FPGA，给出顶层模块与关键子模块的 RTL 代码（Verilog/VHDL），如 DDS、FIR 滤波器、CORDIC、FIFO 等，并说明时钟域、接口时序与参数化位宽的选取依据。
- 代码必须有详细中文注释，解释每一段的功能以及参数选择的原因，保证稍加适配即可在具体器件上运行。
- 涉及固定参数（如采样率、FFT 点数、滤波器阶数等），必须根据赛题指标明确计算并定义为宏或常量。

### 三、Simulink 仿真（完整 + 子任务）
请提供两套 Simulink 仿真内容：
1. **完整全链路仿真模型**：一个涵盖信号产生、模拟调理、ADC采样、数字处理、DAC恢复的完整 Simulink 模型。使用 MATLAB 脚本自动生成该模型（.slx），脚本中应用 `new_system`、`add_block`、`set_param`、`save_system` 等函数，并配置好所有模块参数。模型中必须加入必要的观测点（示波器、频谱仪等）以验证指标。模块参数均按关键指标设置，使用理想行为级模型，但在注释中说明实际器件的非理想因素。
2. **子任务仿真模型**：将完整链路拆分成若干独立可仿真验证的子模块，每个子模块对应一个 Simulink 模型（或同一模型中的独立子系统），并给出相应的生成脚本。例如：
   - 子任务1：仅模拟前端（放大器+滤波器）的仿真模型；
   - 子任务2：ADC采样与量化模型；
   - 子任务3：数字处理算法模型；
   - 子任务4：DAC重建与平滑模型等。
   每个子任务模型同样需提供观测点，便于分步调试与指标验证。请明确标注各子任务的信号流向和连接关系。

### 四、MATLAB 链路演示（完整 + 子任务）
请提供两套 MATLAB 脚本：
1. **完整全链路仿真脚本**：一段可直接运行的 MATLAB 代码，严格按照赛题规定的信号参数生成输入信号，逐步实现：模拟前端数学模型（增益、滤波）、ADC量化（按指定分辨率）、数字信号处理算法（FIR/IIR滤波、FFT、解调、参数测量等）、DAC重建与平滑。显示关键节点波形（时域）和频谱（频域），并计算所有要求的技术指标，输出是否达标。代码清晰分段，注释完整。
2. **子任务脚本**：将上述全链路拆分为若干独立的、可单独运行的脚本，每个脚本完成一个处理步骤的仿真与验证。例如：
   - `task1_signal_gen.m`：信号产生与模拟前端建模，显示输入波形和频谱；
   - `task2_adc_quantize.m`：ADC量化效果分析，显示量化前后对比；
   - `task3_digital_proc.m`：数字滤波/FFT等算法验证；
   - `task4_dac_reconstruct.m`：DAC重建与指标核算。
   每个子任务脚本均需输出该步骤的关键波形和中间指标，方便逐步确认系统是否达标。

### 五、Draw.io 链路设计（完整 + 子任务）
请提供两层 Draw.io 框图设计，均以完整的 XML 代码形式给出，用户保存为 .drawio 文件后可直接打开编辑：
1. **完整系统顶层电路框图**：一张图展示从传感器/信号源、模拟调理链路、ADC、处理器、DAC、输出缓冲/驱动到电源模块的完整硬件连接。信号流方向用箭头清晰标注。每个功能模块内部仅标注模块名称和关键指标参数（如“放大器 G=10, BW=1MHz”、“ADC 12bit, 1MSPS”），不得出现具体器件型号。使用不同颜色区分模拟、数字、电源区域，布局美观整齐。
2. **子任务详细设计框图**：针对完整框图中的每个关键功能模块（如放大器、滤波器、ADC接口、处理器外围、DAC缓冲等），分别提供独立的详细框图，进一步展开内部信号流、关键元件连接（仍只标指标，不标型号）以及测试点。每个子框图同样需清晰标注信号流向，并在标题中说明对应哪个子任务。若 XML 代码过长，可分段给出，但务必完整有效。

### 六、Log.html 分阶段任务指导手册
最后，生成一个完整的 HTML 文件，保存为 Log.html。这不是简单的待办列表，而是一份**分阶段任务指导手册**，用来指导参赛者逐步完成实物搭建、代码编写、仿真验证和指标自检。内容必须包含以下几个阶段（可依据赛题实际增减），每个阶段下再拆分为若干具体步骤，步骤描述要具有可操作性：

**阶段划分示例（请根据赛题灵活调整）：**
- 阶段一：方案理解与仿真环境搭建
- 阶段二：模拟前端电路搭建与测试
- 阶段三：ADC 采集与处理器基础配置
- 阶段四：核心算法实现（FFT/滤波/解调等）
- 阶段五：DAC 输出与重建滤波器调试
- 阶段六：系统联调与指标测量

**每个步骤需包含以下信息：**
1. **任务描述**：这一步要做什么（比如“焊接放大器电路，设置增益为 xx dB”）。
2. **参考输入/资源**：该步骤可参考前文哪个部分（例如“参考赛题分析第4节放大器指标”或“参考代码中的 XXX 函数”）。
3. **预期中间结果/波形**：用文字描述预期的输出波形特征、电压范围、频谱形状等（例如“在放大器输出端应观察到 1Vpp 的正弦波，无明显失真”）。
4. **自检方法**：如何判断这一步成功了（例如“用示波器观察输出，对比仿真中的 figure 2，幅度误差 < 5%”）。

**页面交互要求：**
- 每个步骤前方带有一个复选框，勾选后自动更新顶部进度条和完成计数。
- 进度状态通过 localStorage 自动保存，刷新不丢失。
- 提供“重置进度”按钮。
- 整体设计简洁、适合竞赛现场快速核对，使用纯 HTML/CSS/JS 实现。
- 输出完整的 HTML 源代码，从 `<!DOCTYPE html>` 到 `</html>`，用户直接保存为 Log.html 即可。

### 七、提问题清单（Markdown）
基于对赛题的深入分析，整理出一份可以向组委会提问的问题清单，以 Markdown 格式输出（用代码块包裹完整的 .md 内容）。问题应覆盖以下几类：
1. **指标模糊点**：题目中哪些指标表述不够清晰，可能引起不同理解（如“有效值”与“峰峰值”未明确、测量带宽未指定等）。
2. **测试条件确认**：测试时信号源的内阻、测试仪器的加载方式、评委测试流程（如是否允许预热、是否可调电位器）等需要明确的事项。
3. **器件限制与替代**：如果题目指定的器件无法获得或已有库存型号不同，需要确认是否允许替代及替代的具体条件。
4. **评分细节**：哪些指标是主要得分点，哪些是加分项，是否存在一票否决的硬性指标，对作品的稳定性、可靠性有无额外要求。
5. **任何赛题中可能存在的歧义或遗漏**。

每个问题应使用清晰的疑问句，并标注提问的缘由（简短即可）。最终 Markdown 文件的结构示例：
```
# 电赛信号类赛题提问清单

## 1. 指标模糊点
- [ ] 问题1：xxx？ （缘由：xxx）
- [ ] 问题2：xxx？ （缘由：xxx）

## 2. 测试条件确认
- [ ] ...

## 3. 器件限制与替代
- [ ] ...

## 4. 评分细节
- [ ] ...

## 5. 其他疑问
- [ ] ...
```
清单中的问题前置复选框，方便打印后勾选已提问项。Markdown 代码块必须是完整可复制保存为 `questions.md` 的内容。

----------
请务必一次性按上述顺序输出全部七部分内容，各部分之间使用一级标题（###）分隔。若赛题中部分信息缺失，可基于电赛常规做法进行合理假设，并在该处注明假设内容。
````
