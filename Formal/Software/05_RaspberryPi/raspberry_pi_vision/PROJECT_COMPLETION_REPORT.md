## 🎯 核心功能实现

### 算法设计

#### 圆形判定标准
```python
is_circle = (
    圆度 ≥ 0.75        AND  # 形状接近圆形
    轴比 ≤ 1.25        AND  # 长短轴接近相等
    覆盖率 ≥ 0.70      AND  # 轨迹完整
    对称性 ≥ 0.65           # 四象限对称
)
```

#### 质量评分公式
```python
quality = (
    40% × 圆度分数 +
    25% × 轴比分数 +
    20% × 覆盖率分数 +
    15% × 对称性分数
)
```

#### 扫描策略（双向）
```
中心频率fc
扫描序列: fc, fc+100, fc-100, fc+200, fc-200, ...
提前停止: quality ≥ 90
扩展范围: 初始±500Hz → 扩展±1000Hz
```

### 工作流程

```
┌─────────────────┐
│ 开始 (目标2)    │
└────────┬────────┘
         ↓
┌─────────────────┐
│ 粗测频率        │  使用现有算法
│ (COARSE)        │  100/500/2000us探测
└────────┬────────┘
         ↓
┌─────────────────┐
│ 精测相位        │  使用现有算法
│ (FINE_PHASE)    │  3ms/7ms双探测
└────────┬────────┘
         ↓
┌─────────────────┐
│ ★圆形扫描★     │  ← 新增功能
│ (CIRCLE_SCAN)   │
│ • 规划扫描点    │  fc ± 500Hz, 步进100Hz
│ • 逐点测试      │  每点settle+capture
│ • 评估圆度      │  圆度/轴比/覆盖/对称
│ • 选择最佳      │  quality最高的频率
└────────┬────────┘
         ↓
┌─────────────────┐
│ 跟踪调整        │  使用现有算法
│ (TRACK)         │  微调幅度和相位
└────────┬────────┘
         ↓
┌─────────────────┐
│ 锁定保持        │
│ (LOCKED)        │
└─────────────────┘
```
